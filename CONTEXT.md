# Context

Northroom shows a folder on your computer as it is. You run your own AI agents in terminals
inside the app, and they make and change files with their own tools. There is no Northroom file
format (ADR-0003), no account (ADR-0008) and no backend (ADR-0006).

| Settings file | `~/.config/northroom/settings.json` (`%APPDATA%\Northroom` on Windows). Holds the drive and appearance. The app, the person or an agent can edit it; changes apply live (ADR-0014).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| Changes       | What the terminals changed on disk in a root (a repository's top folder, else the drive) since you last kept it. A flat list of the files sits beside one continuous diff of them all; the file scrolled into view is lit in the list and its name line stays pinned at the top of the diff. Long lines wrap to the diff's width, so nothing scrolls sideways; the list and the diff scroll on their own. Under the pointer a name line shows Keep and Undo for its file (beside Open for a file without a text diff) and a hunk shows them at its first row's right end. Keep (⌘Y, ⌘⇧Y for the file) takes the change into what the file is diffed from, deleting nothing: a kept hunk leaves the diff, and a file kept whole leaves the list until a terminal changes it again; your own edits and other programs' don't bring it back. Undo (⌘⌥Z, ⌘⇧⌥Z for the file) puts it back as it is diffed from, the agent's starting version or what you last kept (a new file is deleted), after moving the file's current version to the Trash; ⌘Z right after puts it back. A file's section collapses to its name line by a click; noisy files (large diffs, lock and generated files, deleted files, media) start collapsed. Changes made while no turn ran are left out. The list survives a restart: a small per-root record in the app's data keeps each listed file's baseline and credit and what was kept of each file, and a file put back as it was drops off. The sessions menu's Review changes says how many files are listed ("· 4 files") and is off at none. Opens as a tab (ADR-0002). |
| Terminal      | A `.nterm` file that opens your shell in its folder. The app knows which agent runs in it (ADR-0005). Its session is labelled by the task the program reports in its title, else by the file's name.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |

## Who owns what

| Area                                     | Owner                                                   |
| ---------------------------------------- | ------------------------------------------------------- |
| Rules, state, layout, words and requests | Core, `apps/native/core`                                |
| Drawing, input and platform calls        | GPUI shell, `apps/native/gpui`                          |
| Live HTML pages and 3D stills            | Core `page/host/` with the shell's `webhost`            |
| Updates                                  | GitHub releases, checked and verified in core `update/` |
| A paired phone's link (ADR-0016)         | Core `remote/` with `crates/northroom-link`             |
| Marketing, FAQ, download and legal pages | The `main-eng/northroom-web` repository                 |

## Rules of thumb

- Media time is seconds, durations are milliseconds, layout is points from the top-left.
- Parse untrusted input where it enters, then trust the type.
- Use `Option` for absence, with one stored form for "none".
- Before retrying an approach, check whether [DECISIONS.md](DECISIONS.md) rejected it.
